# My Spotify Current Listens 🎵
I made a little website with a widget that shows what I'm playing on Spotify and my all time top 5 in Spotify.

## Challenges
Some things that were challenging:
1. Learning how to layer the shapes over one another to create the cd player.
2. How to space the cd player and my top 5 songs.
3. How to make the cd player show my current song.

## Use
To see my awesome music taste of course! And to hopefully get some new favorite songs.
## Installation 🔧
If you want to run and view this on your device you have to:
1. **Clone the repository:**
   ```bash
   git clone https://github.com/yaaAfrehb/currentlistens.git
   ```
2. **Navigate to the project folder:**
   ```bash
   cd currentlistens
   ```
3. **Open the site:**
   Double-click the `index.html` file, or right-click it and select **Open with [Your Browser]**.
